# V0.3 一分钟 Demo

## CMD 启动

```bat
scripts\run_dev.cmd
```

打开 <http://127.0.0.1:5173>。

## 60 秒流程

1. `0–10 秒`：首页说明仁怀监测员每天巡查至少 3 次，动作是丈量墙缝、比对每日数据、填写台账。
2. `10–18 秒`：指出当地已有自动化监测设备，人工现场复测仍持续进行。
3. `18–35 秒`：点击“一分钟演示：复测这条墙缝”，看到真实建筑混凝土表面、裂缝和左右视觉复测贴。页面用人话显示身份识别、角度修正、历史对齐、相对张开和记录字段生成。
4. `35–48 秒`：结果页主数字显示“较上次张开 +X mm”，并并排展示上次和本次墙体。
5. `48–58 秒`：人工确认，生成包含监测点、CRACK-W01、日期、张开变化和影像证据的记录。
6. `58–60 秒`：页面收尾——“不是预测山什么时候塌。只是把量一次、比一次、记一次，变成拍一次、确认一次。”

## 口播边界

本项目不声称首创双标志摄影测量，也不替代自动监测设备或贵州既有业务平台。它是人工巡查最后一公里的 measurement layer。公开墙体图片没有真实毫米尺度，演示的 8.0 mm 初始开度和 +5.0 mm 位移均为受控仿真。
