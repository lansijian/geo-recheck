# 一分钟 Demo

## 准备

1. 在 CMD 中运行 `scripts\run_dev.cmd`；
2. 打开 <http://127.0.0.1:5173>；
3. 无实物标靶时使用内置 `+5 mm / 20°` 样本；
4. 有实物标靶时，先在 `/calibration` 完成相机标定并核验打印尺寸。

## 演示流程

1. 首页指出 `GZ-TZ-DEMO-001 / MP-03 / WALL-02`，强调坐标为演示数据；
2. 点击“开始复测”；
3. 点击“加载内置 +5 mm / 20° 样本”或拍摄双侧标靶；
4. 点击“拍摄并计算”；
5. 结果页说明 marker 自动确认身份、位置只是二次校验；
6. 展示上一期 243.2 mm、本期约 248 mm、相对位移约 +5 mm 与正视化证据；
7. 指出当前是演示相机配置，不能外推野外精度；
8. 输入记录人并确认，展示标准记录和打印/PDF；
9. `/benchmark` 的用时数据只来自本机实际点击试验，不预埋贵州现场效率结论。

## 讲解边界

“我们没有预测山会不会塌。我们只把固定监测点的量、比、记变成拍一次、确认一次；模糊、遮挡、角度过大或历史突变时，系统宁可拒绝输出。”
